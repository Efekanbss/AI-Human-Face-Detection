# AI-Human Face Distinction

## About the Project
This repository contains the implementation of the "AI-Human Face Distinction" project, developed for the CENG3522 Applied Machine Learning course. The project aims to automatically detect synthetic, AI-generated images to combat visual misinformation in the era of powerful generative models like GANs.

## Dataset
The models were trained and evaluated using the "140k Real and Fake Faces" dataset from Kaggle. This dataset includes 70,000 real images (sourced from Flickr) and 70,000 synthetic images (generated by StyleGAN), all resized to 256x256.

## Methodology & Approaches
We explored three main detection strategies:
* **Traditional Feature-Based Detection:** Extracting handcrafted visual features (such as Color Histogram, HOG, and LBP) and training classical machine learning models like Random Forest and MLP.
* **Deep Feature Extraction (Transfer Learning):** Using a pre-trained ResNet50 model to extract deep features from the last convolutional layer, which are then fed into classical classifiers.
* **Benchmark Models:** Evaluating state-of-the-art synthetic image detection models (UnivFD and DIMD) from the SIDBench benchmark.

## Key Findings
The Transfer Learning approach (ResNet50 + classical classifiers) provided the best overall performance and balance between accuracy and efficiency. Specifically, using a Multi-Layer Perceptron (MLP) on top of ResNet50 features achieved an impressive accuracy of 95.44%. While state-of-the-art benchmark models showed very high precision, they suffered from low recall and significantly longer runtimes.
